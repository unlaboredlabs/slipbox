# Security

Please report a vulnerability privately through GitHub: on the repository's **Security** tab, choose **Report a vulnerability** ([direct link](https://github.com/unlaboredlabs/slipbox/security/advisories/new)). Do not open a public issue for it.

Say what an attacker can do and how to reproduce it. A fix lands in the `edge` release, which `slipbox update` installs.

Only the latest release is supported.
